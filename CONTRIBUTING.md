# Contributing

Start from the art direction and asset specification. Use an issue to describe the asset or behavior being proposed and its acceptance criteria.

Submit new art as a versioned file; preserve earlier concepts unless removal is intentional. Update the asset catalog with actual dimensions, hash, status, and limitations.

Only contribute material you are entitled to share. Do not include proprietary game files, third-party source art, credentials, or personal machine paths. Describe inspiration without claiming official affiliation.

Pull requests should include a preview, the intended in-game use, and the checks performed. Keep concept review separate from production readiness.
